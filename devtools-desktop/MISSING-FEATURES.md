# DevTools Desktop — 缺失功能清单

> 对比网页版 Deploy Panel 和 Git Weekly Report，桌面版尚未实现的功能汇总  
> 日期：2026-05-13

---

## 一、部署面板缺失功能

### 🔴 关键缺失（核心功能用 alert 占位）

| # | 功能 | 网页版现状 | 桌面版现状 |
|---|------|-----------|-----------|
| 1 | 服务器添加/编辑表单 | 完整表单弹窗（名称、Host、端口、用户名、密码、默认目录、多发布目录标签编辑） | `alert('添加服务器')` 占位 |
| 2 | 添加项目弹窗 | 双模式：自动扫描 + 手动浏览目录，支持批量添加 | `alert('添加项目')` 占位 |
| 3 | 项目默认配置弹窗 | 项目别名、默认 Node 版本、默认服务器多选 | `alert('配置')` 占位 |
| 4 | 自定义确认/提示弹窗 | 自定义 `showConfirm()` / `showAlert()` 替代原生弹窗，带图标和样式 | 使用原生 `alert()` / `confirm()` |

### 🟠 重要缺失（主要功能差距）

| # | 功能 | 说明 |
|---|------|------|
| 5 | 快速复用（⚡） | 网页版有完整的快速复用弹窗：显示最近 10 条成功记录，选择后一键重复执行 |
| 6 | 远程文件浏览器 | 网页版可通过 SFTP 浏览服务器目录，面包屑导航，选择发布路径 |
| 7 | 多服务器部署 | 网页版支持勾选多台服务器同时部署，桌面版只有单选下拉框 |
| 8 | FileZilla 导入 | 网页版支持从 FileZilla sitemanager.xml 批量导入服务器 |
| 9 | 防重复部署锁 | 网页版有 `busyProjects` 机制，任务进行中禁用按钮显示进度 |
| 10 | 日志搜索（Ctrl+F） | 网页版日志弹窗支持关键词搜索、高亮、上下跳转 |
| 11 | 部署弹窗内快速测试连接 | 网页版部署弹窗底部有「🔗 测试连接」按钮，并发测试所有选中服务器 |

### 🟡 中等缺失（体验优化）

| # | 功能 | 说明 |
|---|------|------|
| 12 | 任务恢复（刷新后恢复） | 网页版刷新页面后可恢复正在执行的任务，回放已有日志 |
| 13 | 日志弹窗最小化 | 网页版关闭日志弹窗时任务继续后台运行，Toast 提示可重新打开 |
| 14 | 项目卡片最近部署信息 | 网页版每个项目卡片异步加载并显示最近一次部署的状态和时间 |
| 15 | 历史批量操作 | 网页版支持批量选择 + 批量删除 + 自动整理（按天数/项目保留策略） |
| 16 | 历史状态筛选 | 网页版同时支持按类型（部署/构建）和状态（成功/失败）筛选 |
| 17 | 历史统计栏 | 网页版顶部显示总数、成功数、失败数 |
| 18 | Git 提交预览 | 网页版构建/部署弹窗内显示项目最近 5 条 git commit |
| 19 | 模块搜索 | 网页版模块选择网格有搜索输入框，可快速定位模块 |
| 20 | 记住上次选择 | 网页版自动记住每个项目上次选择的模块，下次打开自动勾选 |
| 21 | 移除项目 | 网页版项目卡片有删除按钮，桌面版没有 |
| 22 | 项目筛选增强 | 网页版有「已配置」「未配置」筛选，桌面版只有全部/多模块/单体 |

| 36 | 统计信息栏 | 网页版显示仓库数、提交数、空仓库数、失败数 |

## 三、后端 API 缺失

桌面版 sidecar 后端路由已从网页版复制过来，但前端未对接的 API：

| API | 用途 |
|-----|------|
| `GET /api/deploy/last/:projectName` | 项目最近一次部署信息（卡片展示用） |
| `GET /api/deploy/recent/:projectName` | 最近成功记录（快速复用用） |
| `GET /api/deploy/active` | 活跃任务恢复 |
| `POST /api/servers/:id/quick-test` | 快速连接测试（同步返回） |
| `POST /api/servers/:id/browse` | 远程目录浏览 |
| `GET /api/servers/filezilla` | FileZilla 配置检测 |
| `POST /api/servers/filezilla/parse` | 解析 XML |
| `POST /api/servers/filezilla/import` | 导入服务器 |
| `GET /api/projects/browse` | 本地目录浏览（手动添加项目） |
| `GET /api/projects/:name/git-log` | 项目最近 git 提交 |
| `DELETE /api/history` (body: ids) | 批量删除历史 |
| `POST /api/history/cleanup` | 自动整理历史 |

## 四、建议实现优先级

### 第一优先级（让核心操作可用）
1. 服务器添加/编辑表单弹窗
2. 添加项目弹窗
3. 项目配置弹窗
4. 自定义确认/提示弹窗（替代 alert/confirm）
5. 防重复部署锁

### 第二优先级（补齐主要功能）
6. 多服务器部署支持
7. 快速复用功能
8. 远程文件浏览器
9. 日志搜索
10. 周报日期快捷按钮 + 增量加载
11. 周报摘要生成

### 第三优先级（体验优化）
12. 项目卡片最近部署信息
13. 任务恢复
14. 历史批量操作 + 自动整理
15. FileZilla 导入
16. 按日期视图
17. 提交搜索
18. 模块搜索 + 记住上次选择

### 第四优先级（锦上添花）
19. 仓库拖拽排序
20. 配置导入/导出
21. 下载 Markdown 文件
22. 系统原生通知（Tauri）
23. Git 提交预览
