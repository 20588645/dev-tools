最小窗口并排对照覆盖了 900 × 320 的整个顶部关键区域，标题、说明、主操作、搜索、筛选、状态和正文起点均清晰可读，因此无需再裁更小的局部图。对照确认 Toolbar 在该窗口下最多两行，未发生横向溢出、标题与操作碰撞或顶部压住正文。

## Required fidelity surfaces

- 字体与排版：使用 Apple 系统字体与中文系统回退；标题 18～20px、正文控件 12～13px，字重和行高形成稳定层级。长说明在窄窗口受控，不进入操作区。
- 间距与布局节奏：默认工具页顶部为 111px，简单页为 57px；最小窗口工具页约 149～157px。部署面板因同时拥有子导航与两行工具栏为 202px，仍保留完整正文空间。正文是独立滚动容器。
- 颜色与 Token：Primitive → Semantic → Component 三层 Token 已用于亮暗主题。小号蓝色文字采用 `#3269cc`，白底对比度约 5.21:1；亮色三级文字采用 `#687587`，白底约 4.68:1；暗色三级文字采用 `#8d9aaa`，深色底约 6.30:1。暗色主按钮单独使用深蓝背景，避免亮蓝底白字对比不足。
- 图像与图标：页面没有需要生成的位图资产；所有结构性图标均来自 Iconify 的 Tabler 图标库，没有 Emoji、手绘 SVG 或 CSS 代画图标。
- 文案与内容：14 个页面名称、说明、操作、筛选和状态均依据现有项目功能与审计结果；正文仅使用代表性模拟数据帮助判断顶部与工作区的关系。

## Findings

- 当前没有未解决的 P0、P1 或 P2 问题。
- P3：HTML 设计预览通过 CDN 加载 Iconify；正式 Vue 组件开发时应改为项目内打包的图标组件，避免离线环境依赖 CDN。
- P3：原型的正文只用于验证顶部关系，不代表每个业务页面最终视觉稿。

## Comparison history

### Iteration 1

- 早期问题：默认工具页顶部为 125px，高于规格建议的约 104～112px；最小窗口侧边栏中的“2FA 账号列表”发生换行；亮色三级文字和亮蓝按钮存在小字号对比度风险。
- 修复：压缩 PageHeader 与 Toolbar 高度；侧边栏标签改为单行省略；分离信息强调色与主按钮背景色，并提高亮暗主题中的文字与边框对比度。
- 修复后证据：默认工具页顶部 111px；14 个页面在 1665 × 1184 和 900 × 600 下均无页面、顶部或正文横向溢出，无标题操作碰撞，无顶部正文重叠。
