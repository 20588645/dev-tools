# 待办看板卡片紧凑性重构与视觉美化方案

用户反馈在“待办看板”页面中，待办卡片在列中被过度拉伸，留白巨大且单调。本计划旨在从 CSS 层面解决卡片非自适应高度拉伸问题，并全方位提升待办卡片的设计精致度。

---

## 1. 问题根源分析
1.  **高度拉伸 (Stretch)**：由于待办列容器 `.todo-column-list` 使用了 `flex: 1` 占据列的全部高度空间，在其为 `display: flex; flex-direction: column` 布局时，如果只有一个卡片，且没有强制约束子卡片的主轴拉伸策略，部分 WebView 渲染引擎可能会拉伸该子元素以试图填充区域，造成卡片内部产生虚空的白色间隙。
2.  **视觉材质单一**：卡片缺乏毛玻璃和发光渐变感，进度条和复选框组件的设计不够精致。

---

## 2. 解决方案与重构代码

### 2.1 强制高度自适应与 gap 间距约束
为 `.todo-card` 增加强力的主轴约束属性，阻止任何不必要的拉伸，确保高度 100% 由内容紧凑撑起：
```css
.todo-card {
  height: auto !important;           /* 强制高度自适应，消除大白 */
  flex: 0 0 auto !important;          /* 坚决不被容器拉伸高度 */
  display: flex !important;
  flex-direction: column !important;
  gap: 8px !important;                /* 强制子项紧凑排列 */
}
```

### 2.2 视觉精致度提升 (Rich Aesthetics)
1.  **卡片材质升级**：背景替换为半透明深色玻璃 `rgba(255, 255, 255, 0.02)`，搭配 `border: 1px solid rgba(255, 255, 255, 0.07)` 细线发光边框，悬停触发 `translateY(-3px)` 微动效以及淡蓝霓虹投影。
2.  **细长发光进度条**：进度条高缩减为 `4px`，背景更加通透，填充部分使用渐变霓虹光。
3.  **精细化 Checklist 子项**：对复选框按钮、选中态图标以及勾选线划过渡动画进行微调，提升质感。

---

## 3. 验证计划
1.  **高度自适应核验**：打开待办看板页面，观察仅有一个待办卡片时，卡片高度是否缩减为紧凑状态，大空白是否完全消失。
2.  **视觉效果核验**：悬浮在卡片上，检查微弱浮动及霓虹投影。
