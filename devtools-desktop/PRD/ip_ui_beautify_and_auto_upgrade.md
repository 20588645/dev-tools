# IP 纯净度卡片美化与软件自动检查更新 PRD

为 DevTools Desktop 引入更高级的视觉交互设计，提升 IP 纯净度检测看板的视觉表现力（消除“单调”感觉），并为应用增加后台自动检查更新及一键无感升级的全新交互体验。

---

## 1. 业务背景与用户痛点

- **用户痛点 1（界面单调）**：当前的 IP 纯净度页面由大量的纯文本列表构成，虽然已经做了简单的双栏和星级展示，但色彩结构扁平，在大屏下显得十分单调，缺乏视觉焦点和高级质感。
- **用户痛点 2（更新繁琐）**：当前软件更新必须由用户手动点击切换到“设置”页面，再等待触发检查。当发布新版本时，用户无法主动在全局页面感知更新，不利于快速修复 Bug 及迭代体验。

---

## 2. 功能设计与技术方案

### 2.1 IP 纯净度模块界面大美化 (Aesthetics & UX Refinement)

#### A. 左栏“网络与地理资产”重构
- **图标化与栅格重组**：将 7 个资产项（IP地址、地理位置、ASN、ASN所有者、企业、经纬度、共享人数）由垂直/单调文本改造为“网格卡片”。
- **精美小图标包装**：每个卡片左侧增加一个带半透明渐变底色的微图标（使用对应主题色的 Emoji），右侧为信息主体（标签 + 对应的值），使布局富有层次感。
- **突出首卡**：针对“IP 地址”主项，采用更宽的卡片占满首行，并采用蓝-青渐变背景流光及微外发光。

#### B. 右栏“风控与业务场景推荐”美化与核心卡片集结
- **综合风控值卡片**：
  - **动态氛围呼吸光**：根据获取到的风控分值（Safe / Clean / Warning / Danger），动态调整右侧大卡片的内边框色及外围的微发光投影（Glow Shadow）。
  - **进度条轨道美化**：使用更粗的渐变流光进度条，增加半透明立体轨道及末端白色闪耀呼吸点。
- **共享人数评估大卡片 (新增)**：
  - **由左侧平移至右侧核心展区**：由于“风控值”和“共享人数”是用户最关心的两个核心指标，故将“共享人数”从左侧网格删除，并在右侧显式制作成独立的大仪表盘卡片。
  - **独享度进度条**：根据共享等级提供专属独享率（95% 极好、70% 良好、40% 较差、15% 极差），配备独立的彩色发光进度条和水波纹指示点。
  - **动态氛围呼吸光**：大卡片周围根据共享状态（Safe 绿/ Clean 蓝/ Warning 黄/ Danger 红）晕染出专属背光氛围灯效果。
- **场景评估卡片 (`scene-recommendation-card`)**：
  - 采用 **Glassmorphic** 毛玻璃高透明度底纹，悬停时触发微小的 3D 上浮动画和高对比度边框。
  - 优化左侧图标背景，将其修改为与卡片整体色相契合的半透明磨砂玻璃渐变底框。
  - 给星级（`scene-stars`）添加轻微的发光阴影动效（Text Shadow Neon）。


### 2.2 自动检查更新与全局交互 (Auto Upgrade & Global Notification)

#### A. 全局自动检查更新机制
- **后台自动轮询**：软件在启动后延迟 5 秒（避开首屏加载）自动在后台请求 `/api/upgrade/check`。同时每隔 2 小时自动触发一次更新检查。
- **系统通知提醒**：当检测到有新版本（且本地配置允许通知）时，自动发送系统通知：“有新版本可用，点击即可快速重启更新”。

#### B. 侧边栏“发现新版本”浮标
- **有新版本时的常驻提示**：在侧边栏底部（“收起”上方）增加一个精美、小巧的升级通知气泡按钮 `id="sidebarUpdateBadge"`，当且仅当检测到新版本时以 `display: flex` 渐变动画显现。
- **炫酷动效**：浮标具备左右脉冲闪烁的呼吸灯（Pulse Dot）和深紫-靛蓝渐变流光，极其醒目。
- **一键更新交互**：用户在任何页面，只需点击该浮标，将直接触发更新确认弹窗。用户确认后，软件自动切换至设置页面，并拉起更新进度覆盖层（Upgrade Modal），执行拉取代码、重新编译打包并自动重启，实现完全闭环的“一键傻瓜式升级”。

#### C. 设置页面“自动检查更新”开关
- 在设置页“通用”板块，增加“自动检查更新”开关，控制上述逻辑的启用状态，默认为开启状态。
