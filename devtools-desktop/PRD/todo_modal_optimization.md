# 待办看板弹窗美化与易用性优化需求文档 (PRD)

## 1. 概述
用户反馈，当前“待办看板”页面的任务新建弹窗与编辑弹窗在视觉上不够美观，且存在无法灵活选择任意日期的使用痛点。本项目旨在对这两处弹窗进行深度的视觉美学升级和交互流改善，使其兼顾 Rich Aesthetics（富美学）和极致的易用性。

## 2. 痛点分析与改进目标
- **视觉粗糙**：原弹窗的深色输入框死板，使用了 Emoji 字符，控件排版拥挤。
- **日期选择受限**：原先只提供了“今天、明天、后天、下周”的快速选择，原生的任意日期输入框被 `display:none` 隐藏，导致用户无法指定其他特定日期。
- **小时和分钟选择不直观**：下拉 select 没有展开箭头的提示，排版像是死框，用户体验生硬。

**优化方案**：
1. **磨砂玻璃弹窗**：使全局 `.sys-dialog` 获得高颜值模糊圆角，同时在待办激活时使用专属样式类加宽并调整内部网格。
2. **暴露并美化任意日期选择**：引入可见的 `<input type="date">` 控件，并配备日历 SVG 图标，与原有的快速提醒 Chips 配合工作，既保留了一键设置的快捷性，又扩展了任意日期的灵活性。
3. **SVG 图标替换**：将弹窗头部生硬的 Emoji（`📌`/`✎`）替换为优雅的 Lucide 风格 SVG 图标。
4. **统一高端控件**：调整输入框、详细内容文本域的排版；重构小时、分钟 select 为无边框浮动控件，并带有微妙的外发光。

## 3. 具体修改设计

### 3.1 弹窗结构微调 (`todo.js`)
- 在打开新建任务/编辑任务时，自动为全局遮罩层 `#sysDialog` 附加 `todo-dialog-overlay` 类，退出时移除。
- 在 `showAddTodo` 和 `editTodo` 中，动态注入的新提醒选择器 `.remind-picker` 结构中，在保留快速选择按钮的同时，新增一个可见并带有 SVG 日历前缀的 `.remind-date-input` 控件。
- 按钮部分重构成符合全局高级规范的样式，不再使用硬编码的 inline margins。

### 3.2 自定义时间选择器联动 (`todo.js`)
- **`initRemindPicker`**：双向同步，若存在 `existingDate`，提取并赋值给 `dateInput.value`（`yyyy-MM-dd` 格式）；绑定 `onchange` 事件监听，将选择的值同步更新至 `picker.dataset.date`。
- **`setRemindQuick`** 与 **`clearRemind`**：当点击快捷键或清除按钮时，同步修改 `dateInput.value`。

### 3.3 CSS 深度重定义 (`style.css`)
- **待办专属弹窗定制**：给 `.todo-dialog-overlay .sys-dialog` 设置 `width: 480px`（微加宽），并提供更合理的内边距。
- **极客风提醒控制栏**：
  - 将快速提醒按钮改写为芯片（Chips）风格的悬浮样式。
  - 美化 `.remind-date-selector`：通过 flex 布局组合日历 SVG 和自定义日期框，隐藏其原生丑陋边框，仅保留优雅的小圆角与字重。
  - 美化 select 框：使用带阴影的简约数字框，且在 focus 时增加 primary 蓝光边框及微小的高亮阴影。
- **输入表单优化**：加大输入框高度与圆角，输入获得焦点时外围羽化发光，改善输入的手感与视觉回馈。

## 4. 验证计划
- 测试新建任务，依次尝试点击“今天”、“明天”、“清除”按钮，检查页面显示的日期是否正确且同步到 date 控件中。
- 测试点击自定义日期框，查看是否能顺利拉出原生日历并选择下个月或任一天，保存后核查该任务是否被正确记录。
- 测试编辑任务，检查已设定好的任务名称、详情、提醒时间是否已回显到输入框、textarea 以及 dateInput 和 select 中。
- 确认弹窗动画是否平滑，亮/暗模式下的整体色彩是否优雅平衡。
