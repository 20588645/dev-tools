# 待办看板双栏弹窗视觉美化与描述扩展需求文档 (PRD)

## 1. 概述
在上一轮优化中，解决了无法灵活选择日期的问题，但用户指出弹窗整体依然太小，且在填写多行详细任务内容时感到不便。为了彻底解除填写内容的束缚，决定放弃原有的单栏堆叠排版，将其重新设计为“双栏式极客工作流弹窗”。

## 2. 核心痛点与优化设计
- **输入区域狭隘**：当任务名称或多行详细内容字数较多时，旧版垂直单栏把所有内容和时间选择器堆在 480px 的宽度里，使文本框极低矮。
- **重新设计目标**：
  1. **拓宽至 680px 双栏流**：主内容区与时间配置区横向分家，提供类似 Jira/Linear 的专业协作体验。
  2. **左侧主干区 (Main Group)**：独占左侧空间，大幅拉高详细内容 textarea，允许默认显示 6 行，高度自动锁定最小为 `160px`，让编辑体验极致顺畅。
  3. **右侧辅助区 (Sidebar Group)**：将提醒相关的时间设置模块迁移至右侧窄边栏中，通过 2x2 网格排版快捷键、垂直时间框、醒目清除键等在右侧紧凑对齐，不跟左侧的重点输入文字抢夺空间。

## 3. 具体修改设计

### 3.1 页面标记重构 (`todo.js`)
- **双栏容器（`double-column`）**：在 `showAddTodo` 和 `editTodo` 两个主弹窗函数中，将原表单容器重构为包含 `.todo-form-main`（任务名、文本域）和 `.todo-form-sidebar`（时间选择面板）的双列模式。
- **文本框尺寸扩张**：
  - 将 textarea 描述文字框高度设为 `rows="6"`。
  - input 任务名称输入框设为 `todo-title-input` 类，以便为其应用特定的左侧微光或聚焦。

### 3.2 侧边栏布局细节 (`todo.js`)
- 提醒选择器的功能逻辑保持完全一致，但在 HTML 结构中，快捷按钮改用无 margin 的平铺组，小时分钟的 select 与清除按钮（`clearRemind`）在侧边栏做垂直紧凑分列。

### 3.3 CSS 重定义 (`style.css`)
- **超宽弹窗尺寸**：定义 `.todo-dialog-overlay .sys-dialog` 的 `width` 设为 `680px`（保留在小屏幕下的 `max-width: 92vw` 自适应）。
- **双栏网格联动**：
  - `.todo-form-container.double-column` 采用 Flex 布局，中间留出 `20px` 间距。
  - 左侧 `flex: 1` 自动拉伸；右侧 `width: 200px` 固定缩紧。
- **控件极客化提升**：
  - 为文本域及任务输入框引入专属的灰底微透明及淡蓝色外发光获得焦点过渡。
  - 侧边栏中的快捷按钮改写为 2x2 宫格，清除提醒按钮做成平铺条。

## 4. 验证计划
- 启动新版本，检查弹窗宽度是否拓宽为 `680px`。
- 在详细描述框中输入连续 5-6 行以上的大段文字，查看是否有局促拥挤，滚动体验是否良好。
- 测试快捷提醒和自定义日历，核实它们在右侧窄版宽度下的对齐表现是否精准精致。
