# 笔记本页面美化需求文档 (PRD)

## 1. 概述
当前开发工具箱的“笔记本”页面排版较单调，缺少层次感与现代极客风的设计细节。为了让用户在编写和记录笔记时拥有更优质的专注体验与视觉美感，决定对其进行深度的视觉重构与交互微调。

## 2. 优化目标
- **Rich Aesthetics（富美学）**：采用卡片式布局、半透明毛玻璃质感、温和的渐变与呼吸发光，消除视觉上的生硬与廉价感。
- **现代化组件**：将原本简陋的 Emoji 字符按钮全部替换为精致的 SVG 矢量图标（Lucide 风格）。
- **极客态保存指示器**：将原本纯文本的保存提示升级为带动态呼吸效果的多态指示灯（保存中、已保存、保存失败）。
- **Notion 专注排版**：增加编辑器两侧的 Padding 空间（留白），调整字体、字重和行高，使长文阅读更为舒适。

## 3. 具体修改设计

### 3.1 列表面板 (Notebook List)
- **卡片式条目**：笔记列表项不再是硬生生的底线分割，而是重构为带微小圆角 (`border-radius: 8px`) 的独立卡片，卡片之间有外边距。
- **状态微动效**：
  - **Hover 态**：整体微上浮，透出微妙的卡片投影，右侧的排序箭头轻量化显现。
  - **Active 态**：背景变为半透明蓝色渐变，左侧的激活条由直角纯蓝线变为渐变色呼吸高亮线。
  - **置顶态**：添加温和的置顶背景偏色，置顶图标替换为高颜值的 SVG 置顶徽章。
- **搜索与新建栏**：
  - 搜索框内部嵌入精致的放大镜图标，聚焦时产生平滑的外发光光晕 (`box-shadow`)。
  - 新建按钮采用渐变色背景及圆形高颜值设计，悬停时伴有微弱外发光。

### 3.2 编辑器面板 (Notebook Editor)
- **动作按钮 SVG 化**：将“对齐 (≡)”、“置顶 (📌)”、“删除 (🗑)”全部升级为精致的 SVG 矢量图，配合带圆角的悬停淡灰色底块。
- **置顶激活高亮**：当笔记处于置顶状态时，Pin 图标自动点亮为温暖的金黄色，取消置顶时恢复灰度。
- **智能保存状态灯**：
  - **编辑中**：黄色呼吸灯，文字提示“正在编辑...”。
  - **已保存**：绿色常亮微光灯，文字提示“已保存”。
  - **保存失败**：红色警告闪烁灯，文字提示“保存失败”。
- **Notion 专注流排版**：
  - 两侧留出适当的白空间，防止行宽过宽。
  - 行高锁定为 `1.8`，字体为高清晰度系统字族，placeholder 提示修改为轻盈倾斜灰字。
  - 编辑器内粘贴的图片自动包裹阴影与极细圆角边框，显得更为饱满。

## 4. 验证计划
- 在亮暗双色主题下，检查列表卡片悬停和选中高亮色是否和谐。
- 检验各 SVG 图标的显示大小及置顶按钮高亮状态。
- 测试输入时状态灯是否正常在“正在编辑”和“已保存”间正确转换。
