## 2. 冻结目标

正式页面继续采用“笔记导航 + 专注编辑”的双栏心智模型，但不复制旧 DOM 和旧样式：

1. 页面顶部使用公共 `PageTop`，承担页面标题、笔记数量、搜索和新建。
2. 左侧导航展示笔记列表、置顶和排序模式。
3. 右侧编辑区展示标题、保存状态、置顶和更多操作。
4. 默认窗口保持双栏铺满；900 × 600 保持可编辑，并提供列表收起或紧凑模式。
5. 页面不增加强功能仪表盘，不把个人笔记扩张为复杂知识管理系统。
6. 所有表单、按钮、下拉、确认、状态和空状态优先复用项目二次封装组件。

## 3. 所有实现必须包含的可靠性与安全基线

以下内容不因 L2 视觉确认而取消：

- 搜索、切笔记、切页面和关闭窗口前 flush 当前草稿。
- 保存串行化，保存状态绑定笔记 ID。
- 搜索和详情请求使用 AbortController/请求版本，只接受最后一次有效响应。
- Sidecar 断开显示明确错误，不能渲染为“暂无笔记”。
- 历史 HTML 只在允许列表清洗后渲染，不批量覆盖原始历史数据。
- 新保存内容只保留允许结构。
- 图片上传校验 MIME、文件头、扩展名和大小。
- Vue 组件卸载时清理保存计时器、请求和键盘/粘贴监听。
- 保持现有 `notebook_notes` 数据和历史笔记兼容，不清空用户数据。

## 4. 标签功能处理

- PG4 不实现标签筛选、标签展示或从正文提取 `#标签`。
- 搜索只匹配标题和正文，不建立额外分类心智。
- PG5 删除旧页面中的标签 UI、`nbCurrentTag` 全局状态、标签提取和不可达 DOM 查询逻辑。
- SQLite 历史数据中的 `tags` 字段可为兼容既有数据暂时保留，但新 Vue 页面与服务层不读取、不生成，也不因本次迁移改写历史记录。

## 5. 文本对齐快捷键边界

- 保持 `Cmd/Ctrl + Shift + L` 的既有行为兼容。
- 不作为主工具栏常驻按钮。
- 放入“更多”菜单和快捷键说明。
- 必须绑定编辑器生命周期，页面卸载后不得保留全局监听。

### 5.1 粘贴统一、账号信息快捷复制与网页链接

- 文本或 HTML 默认按当前笔记样式粘贴：保留段落、标题、列表、链接、引用、代码和表格等语义结构，删除来源网页的字体、字号、颜色、背景、行高、内外边距、类名和内联样式。
- 图片仍走本地图片上传与安全校验流程，不把网页外链图片直接写入正文。
- “更多”菜单提供“统一整篇格式”，用于用户主动清理历史笔记中的来源样式；本次迁移不自动批量改写历史正文。
- “统一整篇格式”必须进入编辑器撤销历史，执行后允许立即撤销，避免误清理有意保留的结构。
- “更多”菜单提供“插入凭据信息表”，在当前编辑位置生成“项目名称 + 自定义字段 + 记录”的结构化表格；默认提供账号和密码字段，但不把数据模型固定为账号/密码双列。
- 凭据信息表使用明确的“编辑 / 完成”状态：编辑状态允许修改项目名称和字段名称，并分别提供“添加/删除记录”和“添加/删除字段”；至少保留一条记录和一个字段。完成状态下点击任意值单元格即可复制，避免编辑光标与复制动作冲突。
- 删除记录作用于当前聚焦记录；删除字段作用于当前聚焦字段列。增删字段后项目标题的 `colspan` 与每条记录的单元格数量必须同步更新。
- 字段数量较多时只允许编辑器正文区域横向滚动，不得造成页面级横向溢出；默认窗口和 900 × 600 窄窗口均需保持操作入口可见。
- 完成状态下，值单元格悬停或键盘聚焦时轻微高亮并显示小型“复制”提示，成功后短暂显示“已复制”；不再使用与文字分离的浮动复制按钮。
- 普通段落、标题、列表、代码块和普通表格不增加复制状态或复制入口。
- 凭据信息表继续使用受控 `data-notebook-block="credential"`，并使用 `data-credential-project`、`data-credential-field` 和 `data-credential-value` 标记；移除固定的 `data-credential-kind="account|password"` 枚举。HTML 清洗只允许这些固定标记和合法数字 `colspan`，不增加数据库字段或独立账号管理系统。
- 多个项目可以各自建立凭据信息表；同一项目的同构凭据优先新增记录行，字段结构不同的凭据可以建立独立表格。
- `账号 / 密码 / TOTP 密钥`、`AccessKey-ID / AccessKey-Secret` 只是安全模拟示例，用户可以重命名为任意字段。
- 用户需要记录的是生成 TOTP 验证码所使用的长期 Seed/Secret，而非每 30 秒变化的六位验证码。该值按普通自定义字段保存并支持整格复制，不强制关联已有 2FA 账户。
- TOTP Seed、AccessKey Secret 与密码同属高敏感凭据。本轮凭据信息表沿用笔记 HTML 与本地 SQLite 存储，不宣称具备 Keychain、主密码或字段级加密；若用户要求安全凭据库，应另行进入 L3 安全评估。
- 不根据正文内容自动识别账号、密码或令牌，避免普通文本被误转换。
- 保留“复制正文”；`Cmd/Ctrl + Shift + C` 仅在光标位于账号信息值中时复制当前值。
- 复制成功只反馈“已复制此项”，不得把账号、密码、令牌或正文内容写入 Toast、日志、埋点或错误信息。
- 网页链接不做自动识别。用户选中正文文字后，通过“更多 → 将选中文字设为链接”显式创建链接；若选中内容本身是完整 `http/https` 地址则直接使用，否则通过公共弹窗填写跳转地址。
- 普通粘贴、手动输入、回车和历史正文加载均不会自动转换链接，避免误处理正文、账号、密码或令牌。
- 链接只允许 `http` 和 `https` 协议。普通单击保持编辑页不跳转；`Command + 单击`才调用 Tauri 系统 opener 在默认浏览器中打开。
- 正式 Vue/Tauri 实现不得依赖普通 `window.open` 承担外部跳转；原型中的 `window.open` 只用于浏览器环境演示。
- 凭据信息表只是笔记内的结构化编辑与复制能力，沿用现有本地笔记存储，不宣称具备密码管理器级加密；若后续需要安全凭据库，必须单独评估 macOS Keychain、主密码、自动锁定和剪贴板清理。
- 原型与自动化测试只能使用模拟账号，不把用户截图中的真实敏感内容写入仓库、测试数据或验证产物。

## 10. 凭据表后续交互决策

根据真实历史笔记中的使用反馈，凭据表继续冻结以下规则：

1. 删除或完成编辑时自动清理单元格尾部无内容的浏览器占位节点，避免不可删除的空行；不删除中间的有效换行。
2. 新增字段名称为空，“字段 N”只是占位提示，不属于笔记正文。
3. 中文输入法组合期间不触发正文同步，组合完成后再保存。
4. 每张凭据卡的标题单元格内部始终保留独立编辑图标，操作节点随卡片正文一起滚动。
5. 点击编辑图标后，增删记录、增删字段和完成按钮直接在当前卡片标题区域展开；取消 hover、编辑器外部浮层和滚动坐标换算。运行时操作节点在序列化前移除，不写入笔记 HTML。
6. 完成按钮与 `Command/Ctrl + S` 都会结束凭据表编辑并触发保存。

本轮不改变 SQLite 表结构、Notebook API、历史 HTML 存储格式或凭据复制语义。

本轮真实 Tauri 手动 E2E 已由用户于 2026-07-28 确认通过，允许建立独立修复提交并恢复系统设置 PG1。

## 11. 组件架构二次收口（2026-07-31）

本轮不改变已确认的双栏布局、笔记选择、搜索、排序、自动保存、富文本、凭据表或 SQLite 数据契约。架构复核确认富文本 `contenteditable`、凭据表与普通语义表格属于页面专属编辑器宿主；页面操作、反馈和筛选已正确使用项目组件。需要调整的是笔记列表原生选择按钮、BaseCard 内部内容布局覆盖和 BaseInput 内部标题样式覆盖。
