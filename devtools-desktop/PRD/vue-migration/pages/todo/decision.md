## 1. 用户已确认的方向

- 优化等级选择 **L2：自适应个人任务工作台**。
- 在三种视觉探索方向中选择方案一“安静双栏工作区”。
- 制作亮色、暗色、1665 × 1184 默认窗口和 900 × 600 窄窗口 HTML 原型。
- 暂不加入 L3 的详情提醒编辑、提醒版本去重和应用关闭期间后台系统调度。

## 2. 冻结的信息架构

1. 顶部使用公共 PageHeader 语义，保留标题、说明、搜索、全部/今天/已逾期筛选和“新建任务”主操作。
2. 宽窗口保留任务列表 + 任务详情，但面板按内容密度布局，不制造满高空卡片。
3. 900px 窄窗口使用列表/详情主从切换，选中任务后进入完整详情，并提供明确返回入口。
4. 列表继续使用待办、进行中、已完成三状态分组；同名任务通过描述摘要、清单进度和日期区分。
5. 已完成任务不再突出历史提醒；提醒时间仍保持当前一次性提醒数据契约。
6. 详情保留标题、状态、描述、子任务、删除和状态流转；保存状态靠近当前编辑内容。
7. 完成仍有未完成子项的父任务时，必须先确认是否同步完成全部子项。

## 3. HTML 原型范围

`design-preview/todo-l2.html` 使用安全模拟数据，包含：

- 亮色、暗色主题。
- 搜索与全部/今天/已逾期筛选。
- 三状态分组和分组折叠。
- 任务选择、描述摘要、清单进度和日期状态。
- 宽屏双栏与窄屏主从切换。
- 标题、状态、描述、清单编辑和保存反馈。
- 父任务完成确认、删除确认和新建任务弹窗。
- 键盘焦点与减少动态适配。

原型不连接正式 Sidecar、SQLite、提醒轮询、桌面通知或 Tauri。
