## 1. 页面范围

本次门禁覆盖纯净检测页面的查询入口、当前 IP、IPv4、IPv6、域名、输入校验、加载/空/错误/成功状态、网络与地理信息、风险结论、共享人数、原生属性、大模型可用性、场景建议、主题和响应式行为。

不包含侧边栏、Vue Router、应用壳、完整首页重构、用量统计页或其他功能页面。

## 2. 已确认的优化等级

| 选择 | 内容 | 原型 | 提交边界 |
| --- | --- | --- | --- |
| L0 | 原样迁移 Vue，只修响应式、生命周期和 CSS 污染 | 不需要 | 一个架构提交 |
| L1 | L0 + 公共组件、间距、字号、错误反馈和交互一致性 | 不需要 | 一个架构/轻优化提交 |
| L2 | 结论摘要优先、技术详情降级、布局与场景表达重设计 | 先确认亮暗主题 HTML 原型 | 一个 L2 + Vue 迁移提交 |
| L3 | L2 + API 数据可信度、上游超时/缓存、来源和降级语义 | 先确认原型和 API 范围 | Vue 迁移与 API 修正独立提交 |

用户已确认采用：**L2 页面重设计 + 独立 L3-A 数据可信度修正**。

用户已于 2026-07-27 确认亮暗主题最终 HTML 原型 `design-preview/ipcheck-l2.html`，PG3 已通过，可以进入 PG4 Vue 实现。

## 3. 已确认冻结范围

### 3.1 L2 页面部分

- 保留当前 IP、指定 IP/IPv6/域名查询和 Enter 提交。
- 顶部形成结论摘要：IP、位置、风险、类型、原生属性。
- ASN、组织、IP 数值和坐标进入次级技术详情。
- 风险保留一套主刻度；共享人数改为明确“估算”的紧凑表达。
- 场景建议用状态标签和简短依据替代星级与霓虹效果。
- 使用项目 `Page*`、`Base*` 和 Feedback 公共组件。
- 900 × 600 切为单列/自适应布局，只允许纵向滚动。
- 输入错误内联展示；请求错误显示页面内重试，不退回初始空状态。
- 统一由 `ipcheck-service.ts` 管理响应类型和摘要转换，首页复用同一口径。

### 3.2 独立 L3-A 数据可信度部分

- 风控服务缺失时显示“风险数据不可用/部分可用”，不再默认 15% 极度纯净。
- 返回共享人数的观测/估算来源和置信边界。
- Sidecar 第三方请求增加超时、部分数据降级、短时缓存和速率保护。
- 修正 latitude/longitude 契约并设计兼容期。
- 明确查询数据会发送给第三方服务的隐私边界。

## 4. 当前已知必须修复项

无论选择 L0～L3，下列问题都属于迁移正确性和质量门禁：

1. 900 × 600 横向溢出、数值逐字换行和风险内容裁切。
2. `ipcValNative` 重复 ID 导致风险摘要属性长期为 `-`。
3. 完整页与首页分别解释同一 IP 响应。
4. 查询竞态、组件卸载后请求和重复提交缺少控制。
5. 36 个 `!important`、全局 `.skeleton`、97 行页面 ID 选择器不得带入 SFC。
6. 空、加载、错误和成功状态必须具备明确语义与重试路径。

- 首次进入、当前 IP、IPv4、IPv6、域名和 Enter 提交可用。
