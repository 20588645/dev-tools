# 快捷命令终端面板多标签页与快捷键功能需求文档 (PRD)

## 1. 背景与目标
在 DevTools Desktop 的“快捷命令”页面中，我们已经集成了终端面板。为进一步提升极客与开发者体验，现需要对终端面板的头部进行升级：
- **移除经典红黄绿 Traffic Light 圆点**：避免视觉冗余与空间占用，替换为现代的多标签页（Tabs）管理区。
- **支持多标签页控制**：允许用户通过加号按钮和 `Command+T` (或 `Ctrl+T`) 快捷键，自由创建、切换和关闭多个独立的终端会话。
- **完善 UI 样式**：确保标签页具有精致的 macOS 桌面级悬浮、激活态样式，且在亮色/暗色主题下都能完美融入界面。

## 2. 功能设计与实现范围

### 2.1 结构调整 (`index.html`)
- 废弃原有的三色控制点 `.terminal-mac-actions`。
- 新增终端标签页区域：
  - `.terminal-tabs-wrapper`: 外层 Flex 容器。
  - `#terminalTabs` (`.terminal-tabs`): 承载动态渲染生成的单个标签。
  - `.terminal-add-tab-btn`: 加号按钮，点击时调用 `createNewTerminalTab()` 新建标签页。
- 调整操作区 `.terminal-panel-actions`：
  - 将连接状态点 `#termStatusDot` 整合至右侧操作按钮左侧，保持右侧布局的紧凑性。

### 2.2 样式升级 (`style.css`)
- 对 `.terminal-panel-header` 结构采用 `align-items: flex-end` 布局，使标签底边与 header 底边无缝贴合。
- 补充定义 `.terminal-tab`、`.terminal-tab.active`、`.terminal-tab-title`、`.terminal-tab-close` 以及 `.terminal-add-tab-btn` 样式：
  - **激活态 Tab**：背景色与下方终端背景色相同，且去除下边框（或使下边框颜色与背景融为一体），呈现与终端面板一体化的视觉效果。
  - **非激活态 Tab**：具有微弱的半透明背景，文字稍微变淡，悬浮时有微亮过渡。
  - **关闭按钮**：只有在标签数大于 1 时显示。悬浮在 Tab 上时呈现淡灰色，悬浮在关闭按钮上时变红/变深，且有微缩放动画。
  - **加号按钮**：虚线描边圆角矩形，悬浮时变为实线并轻微缩放。

### 2.3 快捷键及交互逻辑 (`terminal.js`)
- 在“快捷命令”页面处于 `active` 状态下，拦截全局键盘事件 `Cmd+T` / `Ctrl+T` 并阻止浏览器默认行为，自动触发 `createNewTerminalTab()`。
- 快捷指令卡片点击“▶ 执行”时，应自动写入当前已激活的终端 Tab 的 PTY 会话，并发送回车执行。

## 3. 验证步骤
1. 打开应用，进入快捷命令页面，检查终端面板头部左侧不再有红黄绿三色圆点，取而代之的是 `Terminal 1` 标签和右侧的 `+` 按钮。
2. 点击 `+` 按钮，验证能否新增 `Terminal 2`；使用 `Cmd+T` 快捷键，验证是否能继续新增标签页。
3. 在多个标签页中切换，并执行不同命令，验证各个 Tab 对应的终端内容是否独立保留。
4. 悬浮在 Tab 上点击 `✕` 按钮关闭标签页，验证会话是否被销毁且自动切换至其他 Tab。
5. 在有多个 Tab 的情况下，点击执行上方的快捷命令，验证命令是否只填入并运行于当前激活的 Tab 中。
