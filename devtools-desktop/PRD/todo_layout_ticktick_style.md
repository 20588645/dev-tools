# 待办看板 TickTick 风格扁平双栏布局重构需求文档

## 1. 业务背景与改动动机
用户对原有“待办看板”的三栏卡片式布局不甚满意，主要表现在卡片在被拉高时内部存在大面积无用的黑色空白，非常突兀，且信息密度太低。
为了从根本上解决卡片高度突兀的问题，同时提供更加专业的待办任务管理体验，我们将看板彻底重构为类似 **滴答清单 (TickTick)** 的“中栏极简待办行列表 + 右侧任务详情面板”的现代化双栏布局。

---

## 2. 功能设计与交互逻辑

### 2.1 主体双栏布局 (Dual-Panel Layout)
- **左侧工作栏 (60% 宽度)**：为垂直流式待办列表。
  - 按任务状态（“待办”、“进行中”、“已完成”）分为 3 个分组。
  - 每个分组头部支持折叠/展开交互。
  - 每个任务表现为极其精简的 **任务列表行 (Task Item Row)**。最左侧为状态圆形复选框，中间为任务标题，最右侧是徽章状态区（子任务比值徽标、提醒时间徽标、相对创建时间如“25分钟前”）。
- **右侧详情栏 (40% 宽度)**：为任务详情面板。
  - **默认状态**：当未选择任何任务时，显示精致的“选择任务查看详情” Empty State。
  - **编辑/展示状态**：点击左侧任意一行任务，右侧面板优雅载入当前任务的完整详情，包含：
    - 大标题（支持直接修改失焦保存）。
    - 任务描述备注域（支持大块文本编辑失焦保存）。
    - 细长高颜值的子步骤列表（支持直接在详情板中勾选、输入新增、回车新增下一行、删除子项）。
    - 任务的控制流转状态按钮（如“开始执行”、“完成任务”、“退回”、“删除”）。

### 2.2 自动同步机制 (Auto-Sync)
- 在右侧详情面板中修改大标题、描述备注、增删或勾选子任务时，前端自动调用已有的待办 PUT 接口同步回后端数据库。
- 详情板的数据改动会实时、局部刷新左侧列表中对应的任务行状态（如左侧行的标题、子任务进度徽章会同步变化）。

---

## 3. UI 视觉升级规范 (Rich Aesthetics)
- **主题融合**：全盘采用暗夜星空蓝半透明毛玻璃底板 (`rgba(255, 255, 255, 0.02)`) 辅以极细的发光半透明边框，确保与系统侧边栏、主背景的现代科幻暗色质感融为一体。
- **状态高亮**：被选中的任务行，会获得淡蓝色的微光描边，悬停有柔和的平移浮动微动效。
- **极简化子任务**：在列表主页不再平铺子任务复选框，仅以极小的 `⚏ 0/3` 徽章收纳，彻底去除一切冗余物理高度。

## 4. 落地验证方案
- **交互验证**：在开发环境下启动，打开待办页面，核对左侧行与右侧详情版块的数据流动、折叠展开动画。
- **构建发布**：执行编译脚本将版本升级为 **v0.1.56** 并打包，覆盖安装并交付。
