# Git Weekly Report v2.1 优化方案

## 版本目标
在 v2.0 基础上新增 6 项功能优化，提升实际写周报的效率和体验。

---

## Feature 1：一键生成周报摘要
- **位置**：toolbar 区域新增「📝 生成摘要」按钮
- **逻辑**：解析 commit message 前缀 `feat/fix/refactor/style/chore/docs/perf/test`，按分组 + 类型分类，去重后生成结构化文本
- **输出格式**：
  ```
  【康展项目】
  - 新增：物流首页功能及发布维护页面、合作伙伴展示
  - 修复：PDF导出时间截止问题
  【茅台项目】
  - 新增：进出口报关单据功能页面
  - 优化：拆分总瓶数计算与校验逻辑
  ```
- **交互**：弹出 modal 展示摘要，支持一键复制

## Feature 2：commit 内容搜索/过滤
- **位置**：toolbar 区域新增搜索框
- **逻辑**：实时过滤表格行，隐藏不匹配的 `<tr>`，匹配关键词高亮（`<mark>` 标签）
- **范围**：搜索 commit subject 内容

## Feature 3：按日汇总视图
- **位置**：toolbar 新增视图切换（按仓库 / 按日期）
- **逻辑**：将所有仓库的 commit 按日期合并展示，时间线格式
- **UI**：日期卡片 + 时间线竖线连接

## Feature 4：配置导入/导出
- **位置**：header-actions 区域新增「⬇ 导入」「⬆ 导出」下拉菜单
- **导出**：Blob 下载 JSON 文件（含 repos + token + author）
- **导入**：FileReader 读取 JSON 文件并合并

## Feature 5：增量加载/流式渲染
- **方案**：前端并发请求，逐仓库渲染（不改后端）
- **实现**：新增 `/api/generate-single` 单仓库接口，前端用 Promise.allSettled 并发请求
- **UI**：每个仓库显示独立的加载进度条

## Feature 6：commit 类型标签化
- **位置**：表格 subject 列
- **逻辑**：解析 `feat(xxx):` 前缀，渲染为彩色 pill 标签
- **颜色映射**：feat→绿 fix→红 refactor→紫 style→青 chore→灰 docs→蓝 perf→琥珀
